# Nodesman Homebrew Tap

Official Homebrew tap for native desktop apps and developer tools by Nodesman.

## Available Casks

| App | Install | Description |
| :--- | :--- | :--- |
| **Felt** | `brew install --cask nodesman/tap/felt` | Quiet, featherweight native C++ / Qt 6 markdown writing instrument ([website](https://felt.aramudan.dev/)) |

## Upgrading

```bash
brew update
brew upgrade --cask felt
```
